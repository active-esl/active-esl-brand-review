How to install

Thunderbird — Alex & Michael

  1. Open Edit → Account Settings → [your account] → Composition & Addressing.
  2. Enable Use HTML.
  3. Either paste the signature HTML we will send you into the signature box, or tick Attach the signature from a file instead and point at the HTML file.
  4. Compose a test mail to yourself. Allow remote content once so the brand strip loads from active-esl.com.
  5. Check name, title, phone and WhatsApp look right before sending to customers.

Outlook — Gary

  1. Outlook on the web / Microsoft 365: Settings → Mail → Compose and reply → Email signature. Create a new signature, switch to the HTML / Code view if available, paste the HTML, save, and set it as default for new messages (and replies if you want).
  2. Outlook desktop (Windows): File → Options → Mail → Signatures. New → paste from the HTML file (prefer Paste Special → HTML if plain paste strips formatting). Assign to the Active-Edge account.
  3. Send a test mail to yourself. If the strip is blank, allow download of external images for that message (Outlook often blocks them until trusted).
  4. We can also supply a Word/RTF fallback if HTML paste misbehaves on your build — say if you need that.

Until you say “go”, keep this as review only — do not paste into production mail yet.
