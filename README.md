# active-esl.com

Public website for **Active-Edge** (Active Edge Solutions Limited), served via
GitHub Pages at [active-esl.com](https://active-esl.com).

- **Public site:** HTML at the repository root (promoted from `customer/`).
- **Brand guidelines:** [`brand/`](brand/) (former stakeholder pack).
- **Stakeholder review tip:** branch `review` (or current feature lane) deployed
  with `./scripts/deploy-review.sh` → [review.active-esl.com](https://review.active-esl.com/)
  (Cloudflare Worker assets). Live GitHub Pages / `main` is untouched.

Custom domain (production): `CNAME` → `active-esl.com`.
